## 📌 What is revdiff?

revdiff is a text-based app for reviewing diffs, files, and documents in one place. It helps you scan changes, read content, and add inline notes without leaving the keyboard. It runs in a terminal window on Windows and gives you a clean view for focused review work.

## 💻 What you need

Before you start, make sure you have:
